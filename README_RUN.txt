КАК ЗАПУСТИТЬ LIVE-ПРЕЗЕНТАЦИЮ

1) Распакуйте папку otg_live_app.
2) Запустите:
   ./bin/studio.sh

   Или, если запускаете на Windows:
   python run_presentation.py

Что произойдёт:
- презентация откроется напрямую как локальный HTML-файл;
- localhost и запуск сервера не требуются;
- Chrome for Testing запустится с отдельным demo-профилем и расширением автовхода;
- каждый сервис сразу доступен как стабильная кликабельная демоверсия;
- кнопка LIVE в верхней панели пробует открыть настоящий сайт прямо внутри слайда.
- AIZI подключается в скрытом iframe: текст и голос вводятся на слайде, вопрос уходит на основной сайт, а настоящий ответ возвращается в чат презентации и озвучивается;
- отдельное окно AIZI не открывается.

Пароли не показываются на слайдах. Они используются только в расширении для автоматического входа.

Важно: обычный Google Chrome 137+ запрещает загрузку unpacked-расширения через
--load-extension. Скрипт studio.sh автоматически выбирает установленный Chrome
for Testing, поэтому открывать index.html вручную для live-режима не нужно.

Если iframe не отображается:
- нажмите ↗ на нужном слайде;
- сервис откроется в отдельной вкладке и расширение также выполнит вход.
Это бывает, если сервер запрещает встраивание через X-Frame-Options или CSP frame-ancestors.

Управление:
- стрелки влево/вправо — переключение слайдов;
- клавиши 1–9 и 0 — быстрый переход к слайдам 1–10;
- F — fullscreen;
- LIVE — переключиться на настоящий сайт внутри слайда;
- DEMO — вернуться в стабильную кликабельную демоверсию.
